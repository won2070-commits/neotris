# NEOTRIS — 네온 블록 퍼즐

브라우저에서 바로 즐기는 클래식 테트리스. 설치 없이 실행되고, 휴대폰에서는 홈 화면에 추가하면 앱처럼 전체화면으로 열립니다.

**플레이:** https://won2070-commits.github.io/neotris/

## 조작

**키보드**

| 키 | 동작 |
|---|---|
| ← → | 이동 (꾹 누르면 연속) |
| ↑ / X | 회전 (시계) |
| Z / Ctrl | 회전 (반시계) |
| A | 180도 회전 |
| C / Shift | 홀드 (보관) |
| ↓ | 살살 내리기 |
| Space | 한번에 떨어뜨리기 |
| P / Esc | 일시정지 · S 소리 · R 새 게임 |

**휴대폰 (제스처)**

| 제스처 | 동작 |
|---|---|
| 탭 (오른쪽 ⅔) | 회전 (시계) |
| 탭 (왼쪽 ⅓) | 회전 (반시계) |
| 좌우 드래그 | 손가락 따라 칸 단위 이동 |
| 아래로 쓸기 | 한번에 떨어뜨리기 |
| 위로 쓸기 | 홀드 (보관) |

**테트리스 가이드라인 규격**을 따릅니다 — SRS 회전(월킥·T스핀), 홀드, 다음 5개 미리보기,
7-bag 랜덤, 락 딜레이, 가이드라인 점수표(T스핀 800/1200/1600 · 백투백 1.5배 · 콤보 · 퍼펙트 클리어).

화면 크기에 맞춰 칸 크기를 자동 계산해, 아이폰·안드로이드 어디서든 보드가 화면을 가득 채웁니다(가로로 눕히면 정보 패널이 옆으로 이동). 소리는 🔊 버튼이나 `S` 키로 끄고 켤 수 있고 설정이 저장됩니다.

## 구성

- `index.html` — 게임 전체 (외부 라이브러리 없음)
- `manifest.json`, `sw.js`, `icon-*.png` — PWA (홈 화면 추가·오프라인 실행)
- `build.py` — 배포 빌드: 아이콘·manifest를 내장한 단일 HTML(`NEOTRIS.html`)과 호스팅용 zip 생성

## 개발

```bash
node server.cjs      # http://localhost:5210
python3 build.py     # 단일 HTML + zip 재생성
```

`main`에 push하면 GitHub Pages로 자동 배포됩니다.
